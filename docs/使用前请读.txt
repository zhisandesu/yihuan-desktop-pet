异环小精灵 v1.2.1 · Windows x64 免安装版

启动与更新
1. 完整解压后双击 YihuanCompanion.exe，不要在压缩包内运行。已包含 .NET 桌面运行环境，适用于 Windows 10/11 x64。
2. 已有旧版：彻底退出桌宠，将更新包内容解压到原程序目录，合并文件夹并覆盖同名文件。更新包不能单独运行。
3. 右击角色展开菜单，进入手机；手机包含消息、角色、壁纸、养成、商店、委托、小游戏和设置。
4. 设置 → 连接与声音，填写自己的 API Key 和可用模型。日配仅改变朗读语言，聊天文字默认中文。
5. 已预置中文／日语复刻音色和语音参数。阿里 Token Plan 聊天可共用同一份 Key；其他聊天服务需另填阿里语音 Key。先试听再聊天。
6. 预置音色不转移云端账号权限。若服务提示无权限或音色不存在，请填自己账号的复刻音色 ID。不会回退到系统默认声音。

QQ 陪伴（可选）
1. 给安魂曲准备一个独立 QQ，电脑安装 Windows QQ 与 Edge WebView2。
2. 手机 → 设置 → QQ 同步与主动消息 → 启动 NapCat · 扫码配置。
3. 用安魂曲的 QQ 扫码登录，登录成功后同步连接配置；填入接收消息的 QQ 号，即你的日常账号，启用并保存。
4. 桌面、手机和 QQ 共用本地记录；首次连接不会补发旧记录，内部拖拽等交互说明不发送到 QQ。
5. 支持 QQ 文字、图片与图片表情输入；图片理解需要支持多模态的模型。GIF 只读取首帧，普通编号表情不保证识别。
6. 回复支持文字、复刻语音及按语境概率发送内置表情，可设置免打扰和语音／表情概率。
7. 内置 NapCat 4.18.28 官方原始包；QQ 登录资料和连接口令在本机生成，不随公开包提供。详情及第三方许可见 Connectors/NapCat。

养成与小游戏
聊天、照顾和投喂影响好感，频繁拖动或打扰睡觉可能降低好感。饱腹、精力缓慢变化，仅计算程序运行时间，离线不补扣。
手机 → 商店，用方斯购买番茄、冰箱、玩偶和抱枕。玩偶解锁抱偶互动／睡眠，冰箱可存放番茄并自动补充饱腹。
手机 → 委托，移动鼠标追近蚊子，点击或空格挥拍；三波敌人、连击与星级决定奖励。每天前五轮可得方斯，之后练习。
手机 → 小游戏，鼠标或 A/D、方向键控制角色和篮子接番茄、避开异象；接住16颗额外获得一颗库存番茄，每天最多三颗。
小游戏失焦自动暂停，Esc 暂停，点击继续恢复；中途退出不结算奖励。

数据与使用范围
本包不含作者的 Key、QQ 登录信息、私人聊天或养成存档。个人数据位于 %LOCALAPPDATA%/YihuanCompanion，密钥和聊天记录使用 Windows 用户加密。
聊天会将输入、必要上下文与相关记忆发送至所选服务；图片理解、语音识别和朗读会发送相应内容，费用自行承担。QQ 同步会按配置将真实聊天及角色回复发送到指定接收账号。
长期记忆可在手机查看管理；角色人设固定，记忆和关系成长基于实际对话，模型输出仍可能出现误解或重复。
仅供个人本地、非商业自用。请阅读免责与使用声明.txt；第三方许可见第三方许可及 Connectors/NapCat。
