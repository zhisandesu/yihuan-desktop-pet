异环小精灵 · Windows x64 免安装版

1. 先完整解压文件夹，再双击 YihuanCompanion.exe。不要在压缩包里直接运行。
2. 已包含 .NET 桌面运行环境，无需安装开发工具。适用于 Windows 10/11 64位（x64）。
3. 右击角色打开菜单。拖动角色移动位置；在设置中调整大小、动作与陪伴模式。
4. 本包不含作者的 API Key、聊天记录或账号专属音色配置。
5. 聊天：设置 → API，选择自己的服务，填写自己的 Key 与可用模型，再保存。
6. 语音：填写自己的阿里语音 Key，并分别配置同一账号下的中文/日语复刻音色 ID。作者账号的专属音色不会随程序转移。未配置时不会替换成默认声音。
7. 日配只改变朗读语言；日常聊天、气泡与互动记录默认显示中文。
8. 未配置 API 也能使用角色展示、拖拽、菜单与本地动作；联网聊天、语音和主动台词需要对应服务。

隐私与费用
Key 与聊天记录保存在当前 Windows 用户的本机数据目录，使用系统加密；密钥不写入本程序资源。
聊天会把输入、必要的上下文和已保存记忆发送到你选择的服务；语音识别会上传录音，朗读会上传待朗读文字。模型与语音费用由你与服务商结算。
本机数据目录：%LOCALAPPDATA%\YihuanCompanion。删除数据前先自行备份。
