# 异环小精灵 v1.0.7.2

这次将本地 1.0.4–1.0.7.2 的更新一并发布：聊天能结合语境执行动作，增加番茄小游戏与屏边探头，并修复朗读结束后状态仍停留在“正在说”的问题。

## 更新内容

- **聊天与动作联动：** 根据当前姿态和聊天上下文判断坐下、起身、休息、醒来、变身、飞行及走动。接受动作邀请时可以执行相应动作；普通闲聊不会每次都重置坐姿。实际动作仍遵守姿态转换和拖拽优先规则。
- **番茄小游戏：** 放下番茄后，她可以走近、捡起并吃掉，吃完后的回应继续结合上下文生成。
- **屏边探头：** 人形站在屏幕边缘并空闲一段时间后，有机会走出、探头看看，再回到桌面。聊天、点击和拖拽等交互可以接管，不会强行搬到屏边触发。
- **朗读状态修复：** “准备朗读／正在说／等待后续语音”跟随实际播放进度，结束后恢复；连接长时间无响应时给出超时提示。
- **保留原来的说话节奏：** 缩短首次出声前的准备等待，播放过程沿用原缓冲策略，不通过提高语速或改变音高来加快响应。继续使用安魂曲中文／日语复刻音色。
- **恢复开头语气词：** 正常的“唔、嗯”等会随整句朗读，只合并重复的开头；不会额外叠加预设点击语音。自称与谓语之间多余的标点继续合并。

## 下载与更新

- 首次下载：**YihuanCompanion-1.0.7.2-Windows-x64.zip**。完整解压后运行 `YihuanCompanion.exe`，已包含 Windows x64 所需的 .NET 桌面运行环境。
- 已有 v1.0.0–v1.0.3 完整包，或本地 1.0.4–1.0.7.1：下载 **YihuanCompanion-Update-to-1.0.7.2.zip**。彻底退出程序，将补丁内容解压到原 `YihuanCompanion.exe` 所在目录，合并文件夹并覆盖同名文件。补丁不能单独运行。
- 更新不会替换个人 Key、设置或聊天记录。完整包和补丁都不包含作者的密钥或私人聊天。
- 校验文件：**SHA256SUMS-v1.0.7.2.txt**。公开版本与文件版本为 1.0.7.2，产品版本显示为 1.0.7。
