# 异环小精灵 v1.2.1

这次将 v1.0.7.2 之后的本地更新一并发布：增加手机界面、QQ 同步、记忆与关系成长，以及陪伴养成。驱逐异象重做为平面打蚊子关卡，新增接番茄游戏，商店四件商品分别重绘。

## 手机与 QQ

- 手机界面包含消息、角色、壁纸、情绪、记忆、养成、商店、委托、小游戏和设置，配有蝙蝠手机壳与可切换壁纸。
- 桌面聊天、手机消息与 QQ 共用本地记录。QQ 需给角色准备独立账号，填写玩家接收消息的 QQ 号；内置 NapCat 4.18.28 官方原始包，在手机中扫码并同步配置。电脑需另装 Windows QQ 和 Edge WebView2。
- QQ 支持文字、图片与图片表情输入，多模态模型可以理解图片；GIF 只读取首帧，普通编号表情不保证识别。输出支持文字、复刻语音及按语境概率附带内置表情。
- 修复逐轮回复和语音发送顺序；QQ 回复也可在桌面朗读。内部拖拽／自主动作说明保存在本机，不发送到 QQ，首次连接不补发旧记录。
- 提供 QQ 免打扰、输出语音与表情概率；主动陪伴时机结合养成状态与关系，替换旧的固定／随机主动聊天间隔。

## 记忆与相处

- 增加可管理的长期记忆点、关联检索与后台整理；记忆按实际对话生成，不把图片猜测直接保存为玩家事实。
- 关系从初见逐渐成长，短期情绪和长期熟悉度共同参与回复；角色的底层人设保持固定，避免每次都重复提旧事件。
- 优化最新一轮问题的锚定与重复答案复核，普通对话自然连贯，不强制分成两段。模型仍可能误解、重复或产生不准确内容。
- 日语朗读改用独立的语义保真翻译指令，保留否定、条件、问句、愿望／完成含义与必要语气音。

## 陪伴养成与商店

- 好感、饱腹与精力形成养成循环。聊天、照顾和投喂会增加好感；频繁拖动、反复打扰睡觉以及长期低饱腹／精力会影响好感。变化有间隔与每日上限，仅计算运行时间，离线不补扣。
- 番茄投喂在实际吃完后结算；冰箱存放食物并在饱腹偏低时补充。饥饿提醒、最低饱腹保护与休息衔接按状态运行。
- 用方斯购买番茄、冰箱、蝙蝠玩偶和抱枕。玩偶解锁概率抱偶互动、抱偶入睡／睡眠／醒来；商店使用四张独立生成的透明商品图与大图商品卡。

## 平面小游戏

- **驱逐异象：** 60 秒三波关卡，移动鼠标追近蚊子，点击或空格挥拍。包含体力、动作冷却、延迟命中、连击、快速与双击蚊子、玩偶诱饵。MiniMax 生成持拍走动和挥拍动画。6／14／24 次驱逐对应一／二／三星与20／32／45方斯；不足一星按成绩少量结算，每天前五次完成可得工作奖励。
- **番茄接接乐：** 45 秒，鼠标或 A/D、方向键控制角色与篮子，接番茄、金圈高分番茄并避开异象。达到成绩获得小游戏奖励；接住16颗额外获得一颗真实库存番茄，每天最多三颗。
- 失焦自动暂停，Esc 暂停，点击继续恢复；退出中途关卡不发奖励，同一回合只结算一次。旧版已接的定时委托允许完成或取消，不再提供新接取入口。

## 下载与更新

- 首次下载或早于 v1.0.7.2：**YihuanCompanion-1.2.1-Windows-x64.zip**，完整解压后运行 `YihuanCompanion.exe`。已包含 .NET 桌面运行环境，Windows 10／11 x64。
- 已有 v1.0.7.2 或之后本地版本：**YihuanCompanion-Update-to-1.2.1.zip**。彻底退出桌宠，将内容解压到原程序目录，合并文件夹并覆盖同名文件。更新包不能单独运行。
- 更新包以已发布的 v1.0.7.2 完整包为基线核对，新增资源、NapCat 和所需运行库一并提供。个人数据仍在 `%LOCALAPPDATA%/YihuanCompanion`；包内没有作者的密钥、QQ 登录资料或私人聊天。
- SHA256 校验见 **SHA256SUMS-v1.2.1.txt**。产品版本1.2.1，文件版本1.2.1.0。
