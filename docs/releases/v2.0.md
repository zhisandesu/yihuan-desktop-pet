# 异环小精灵 v2.0

本次更新继续完善桌面动作、QQ 陪伴和日语朗读，保留手机、养成、商店、委托、小游戏与 44 张内置表情。

## 动作与桌面互动

- 角色动作扩充至 108 组，加入连续向左／向右行走、屈膝坐姿和相应姿态衔接。
- 调整连续行走的播放与移动衔接，减少循环中的停顿。
- 修复站立、普通坐姿和屈膝坐姿下，抓住尾巴尖时的拖拽命中与响应。
- 完善投喂番茄的接取位置及动作衔接。

## QQ 与语音

- 改进已有 QQ 登录与连接配置的保留；持续离线时提供提醒。
- 主动聊天的间隔与概率随好感调整，继续遵守免打扰、每日额度和未回复限制。
- 日语朗读结合最近对话、角色心情和当前场景生成独立语气提示。
- 日语默认语速调整为 0.85，中文保持 1.0；日配模式的聊天文字仍默认中文。
- 复刻音色仍需要使用者的 Key 具有对应访问权限。模型偶尔仍会出现停连、音高变化或角色语气偏差。

## 下载与更新

- **首次使用：** 下载 `YihuanCompanion-2.0-Windows-x64.7z`。这是一个完整压缩包，使用支持 7z 的工具完整解压后运行 `YihuanCompanion.exe`，无需另装 .NET。画面无损、资源完整，解压后约 6.6 GB，建议预留 10 GB 空间。
- **已有 v1.2.1 或后续本地版本：** 下载 `YihuanCompanion-Update-to-2.0.zip`，完全退出程序后解压覆盖原程序目录。补丁不能单独运行。
- 更早版本请下载完整包，解压到新文件夹。个人设置、密钥和聊天记录仍由本机用户数据目录读取。
- `SHA256SUMS-v2.0.txt` 提供两个下载包的 SHA-256 校验值。

发布包不包含作者的 QQ 号、登录资料、API Key、私人聊天或个人存档。QQ 接入为可选功能，需自行配置。

适用于 Windows 10 / 11 x64。仅供个人本地、非商业自用；请阅读随包提供的免责与使用声明及第三方许可。
